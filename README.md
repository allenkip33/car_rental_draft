# Car Rental Tracking System

A simple Python command-line car rental system.

## Features

- Register and login users
- Customer and Admin roles
- Add and manage cars
- Rent cars
- Cancel rentals
- Check car availability
- Save data using JSON files

## How to Run

Install the required packages:

python3 -m pip install -r requirements.txt

Run the program:

python3 main.py

## Testing

Run the tests with:

pytest
